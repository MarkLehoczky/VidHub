# VIDHUB

**VidHub** is a video collector, manager and organizer application designed for Windows using *WinUI 3* with *.NET 8.0*.

## Features

- 🖥️ Video displaying
- 📂 Video loading
   - With explicit button
   - With clipboard content
   - With drag&drop method
